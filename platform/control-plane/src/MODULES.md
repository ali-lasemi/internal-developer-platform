# Control Plane Modules

## Service Module

Responsible for service lifecycle.

Capabilities:

- Create service
- Update service
- Retire service


## Template Module

Responsible for template management.

Capabilities:

- Discover templates
- Validate templates
- Generate projects


## Workflow Module

Responsible for workflow coordination.

Capabilities:

- Start workflows
- Track execution
- Report results


## Environment Module

Responsible for environment management.

Capabilities:

- Create environments
- Track status
- Manage configuration


## Identity Module

Responsible for ownership and access context.
