# Developer Portal Backend

## Purpose

Backend service layer powering the Developer Portal experience.

The backend connects user interactions with platform capabilities.


## Responsibilities

- Portal APIs
- User workflows
- Service discovery
- Platform integration
- User preferences
- Portal data aggregation


## Product Role

The backend acts as the experience layer between developers and the platform control plane.


## Main Capabilities

Service browsing

Service creation workflows

Platform information access

Developer notifications

User context management


## Integrations

- Platform API
- Identity Service
- Catalog Service
- Workflow Engine
- Notification Service
