# Developer Portal Design

## Purpose

The Developer Portal is the main product interface for the Internal Developer Platform.

It provides developers with a unified experience to discover, create, manage, and operate services.

---

## Core Experiences

### Service Discovery

Developers can:

- Search services
- View ownership
- Access documentation
- Understand dependencies


### Service Creation

Developers can:

- Select templates
- Create new services
- Generate repositories
- Start delivery workflows


### Service Management

Developers can:

- View service health
- Track deployments
- Access environments
- Manage lifecycle
