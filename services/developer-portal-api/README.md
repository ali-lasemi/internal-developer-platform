# Developer Portal API

## Purpose

Backend API powering the Internal Developer Platform user experience.

It provides a unified interface for developers to discover services, start workflows and access platform capabilities.


## Responsibilities

- Developer portal backend
- Service discovery integration
- Workflow interaction
- Platform capability aggregation


## MVP Capabilities

- Portal health endpoint
- Service overview endpoint
- Workflow launch endpoint


## Future

- Authentication integration
- User preferences
- Team dashboards
- Notifications
- Personalized developer experience
