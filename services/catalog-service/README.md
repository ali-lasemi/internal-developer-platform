# Service Catalog Service

## Purpose

The Service Catalog is the central inventory system of the Internal Developer Platform.

It provides visibility into all managed services, ownership information, lifecycle state and technical metadata.


## Responsibilities

- Store service metadata
- Manage service ownership
- Track lifecycle state
- Provide service discovery capabilities
- Expose service information to platform consumers


## Core Entities

Service

Represents an application managed by the platform.


Team

Represents ownership group responsible for services.


Repository

Represents source code location.


Environment

Represents runtime targets.


Deployment

Represents delivery history.


## Product Value

The catalog creates a single source of truth for engineering services.
