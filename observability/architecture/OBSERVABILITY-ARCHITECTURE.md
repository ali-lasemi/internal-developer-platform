# Observability Architecture

## Layers

Application Layer

Provides application telemetry.


Platform Layer

Provides platform component telemetry.


Infrastructure Layer

Provides runtime information.


## Data Types

Metrics

Used for numerical system measurements.


Logs

Used for detailed event information.


Traces

Used for request and dependency analysis.


## Integration

Observability integrates with:

- Developer Portal
- Service Catalog
- Deployment Platform
- Alerting Systems
