# Developer Experience

## Vision

Create the simplest possible path for engineers to build, deliver and operate software.

The platform should remove unnecessary complexity and provide a consistent engineering experience.


## Experience Goals

Fast

Developers should complete common workflows quickly.


Simple

Complex platform capabilities should feel easy to use.


Guided

The platform should provide clear paths and recommendations.


Reliable

Platform workflows should be predictable and trustworthy.


## Core Experiences

Discover

Find services, templates and platform capabilities.


Create

Generate new services using approved paths.


Deliver

Execute delivery workflows with confidence.


Operate

Understand service health and lifecycle.


Improve

Receive feedback and insights.
