# User Stories

## Developer

As a developer,

I want to create a new service from a template,

so that I can start development without manual setup.


## Developer

As a developer,

I want to see all owned services,

so that I understand my responsibilities.


## Platform Engineer

As a platform engineer,

I want to manage golden paths,

so that teams follow company standards.


## Engineering Manager

As an engineering manager,

I want platform metrics,

so that I can understand delivery performance.
