# Platform Team Guide

## Responsibilities

The platform team builds and maintains internal engineering capabilities.


## Main Responsibilities

Platform Product Management

Defines user needs and priorities.


Platform Engineering

Builds platform capabilities.


Platform Operations

Maintains reliability and support.


## Platform Standards

Every capability should have:

- Clear ownership
- Documentation
- Metrics
- Reliable operation
- User value


## Platform Mindset

Build products for engineers.

Measure adoption.

Improve continuously.
