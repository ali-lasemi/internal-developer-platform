# Developer Guide

## Using The Platform

Developers interact with the platform through self-service workflows.


## Common Activities

Discover a service

Find existing applications and ownership information.


Create a service

Select a template and generate a production-ready foundation.


Manage a service

View lifecycle, health and delivery information.


## Developer Responsibilities

Developers own:

- Application code
- Service documentation
- Service quality
- Service lifecycle decisions


## Platform Benefits

The platform removes repetitive setup work and provides engineering standards automatically.
