# Platform Features

## Feature: Service Catalog

Goal:

Provide a central source of truth for engineering services.


Capabilities:

- Search services
- View ownership
- View metadata
- Track lifecycle


## Feature: Golden Path Creation

Goal:

Allow developers to create production-ready services quickly.


Capabilities:

- Template selection
- Repository generation
- Workflow execution


## Feature: Workflow Automation

Goal:

Automate engineering operations.


Capabilities:

- Workflow execution
- Status tracking
- Notifications


## Feature: Platform Insights

Goal:

Provide engineering intelligence.


Capabilities:

- Metrics
- Analytics
- Adoption tracking
