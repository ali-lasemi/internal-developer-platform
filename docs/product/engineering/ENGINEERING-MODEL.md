# Engineering Model

## Purpose

Define the engineering model behind the Internal Developer Platform.

The goal is to create a consistent way for teams to build, deliver and operate software.


## Engineering Approach

Product Thinking

Platform capabilities are built around real developer problems.


Automation First

Engineering workflows should be automated whenever possible.


Standardization

Common engineering patterns should be provided as reusable capabilities.


Ownership

Every service and platform capability has clear responsibility.


## Engineering Workflow

Discover

Understand available capabilities.


Create

Use approved paths to build services.


Deliver

Automate application delivery.


Operate

Monitor and maintain services.


Improve

Use feedback and metrics to evolve.
