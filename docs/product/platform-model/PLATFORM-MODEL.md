# Platform Model

## Purpose

Define the complete operating model of the Internal Developer Platform as a product.

The platform consists of connected capabilities that work together to improve software delivery.


## Platform Structure

## Experience Layer

Provides developer interaction.

Capabilities:

- Developer Portal
- Service Catalog
- Documentation
- Self Service


## Control Layer

Provides orchestration and coordination.

Capabilities:

- Platform API
- Workflow Engine
- Policy Engine


## Capability Layer

Provides reusable engineering services.

Capabilities:

- Template Engine
- Lifecycle Management
- Identity
- Notifications


## Intelligence Layer

Provides measurement and improvement.

Capabilities:

- Analytics
- Metrics
- Insights


## Platform Goal

Create a unified engineering experience where developers can build and operate software efficiently.
