# Product Epics

## Epic 1: Developer Self Service Platform

Goal:

Enable developers to complete common engineering workflows without manual platform support.


Capabilities:

- Developer portal
- Service catalog
- Service creation
- Service management
- Documentation discovery


Success:

Developers can create and manage services independently.
