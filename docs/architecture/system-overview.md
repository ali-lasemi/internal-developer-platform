# Internal Developer Platform - System Overview

## Overview

The Internal Developer Platform (IDP) is a cloud-native self-service platform for building, deploying, and operating applications.

## Goals

- Developer self-service
- GitOps-based delivery
- Infrastructure automation
- Security by default
- Observability by design

## Core Components

- Developer Portal
- Platform API
- Kubernetes Runtime
- Helm Packaging
- Terraform Infrastructure
- ArgoCD GitOps
- Observability Stack
